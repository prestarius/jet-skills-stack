---
name: grill-me
description: Interview the user relentlessly about a plan or idea, one sharp question at a time, recommending an answer each time. Use whenever the user wants to pressure-test a plan, says "grill me", "poke holes in this", or is about to commit to an approach and wants it stress-tested first.
effort: high
---

Stress-test the plan by interrogating it — one question at a time, hardest assumptions first.

1. **Restate the plan** in a line or two so you're both working from the same understanding.
2. **Find the load-bearing assumptions.** Privately rank what, if wrong, would sink the plan. Attack
   in that order — highest leverage first, not easiest first.
3. **Ask exactly one question per turn.** Make it a sharp fork (a real decision), not a survey
   question. Then **recommend the answer you'd pick and why**, and stop. Wait for the user's response
   before the next question — never batch questions.
4. **Integrate each answer.** Update your model of the plan, surface any contradiction the answer
   creates, and let it reshape which question comes next.
5. **Stop when grilling stops changing anything.** Then summarize: the decisions reached, what changed
   about the plan, and any risk the user is knowingly accepting.

The job is to expose weak points before they cost real work — be direct, not exhaustive. If the plan
is sound, say so and stop rather than manufacturing doubt.
